# আর-রিসালাহ ডিজাইন সিস্টেম

## ১. ডিজাইনের কেন্দ্রীয় ধারণা

আপনি Claude-এর ব্লগের ডিজাইন-ভাষাকে রেফারেন্স হিসেবে উল্লেখ করেছিলেন—পরিচ্ছন্ন কার্ড, সূক্ষ্ম বর্ডার, শান্ত টাইপোগ্রাফি। সেই দর্শন গ্রহণ করেছি। কিন্তু চেহারা নিয়েছি ভিন্ন জায়গা থেকে।

উৎস: **হস্তলিখিত ইসলামি পাণ্ডুলিপি ও বাংলা লিপির নিজস্ব গঠন।**

তিনটি সিদ্ধান্ত এই উৎস থেকে এসেছে:

### ক. রুবরিক (الرُّبْرِيك / লাল কালি)
শাস্ত্রীয় আরবি পাণ্ডুলিপিতে মূল লেখা কালো কালিতে, আর অধ্যায়ের শিরোনাম, বিভাজন-চিহ্ন ও গুরুত্বপূর্ণ সূচক লেখা হতো **লাল কালিতে**। এটিই "rubrication"। আর-রিসালাহতে একটি গভীর, সংযত পাণ্ডুলিপি-লাল (`#8C2B23`) ব্যবহৃত হবে—কিন্তু শুধু তিন জায়গায়:

1. ক্যাটাগরির আইব্রাউ (eyebrow)
2. দীর্ঘ লেখার ভেতরের বিভাজন-চিহ্ন
3. রেফারেন্স ও দলিলের ক্রমিক সংখ্যা

আর কোথাও নয়। বোতামে নয়, লিংকে নয়, ব্যাকগ্রাউন্ডে নয়। এই সংযমই একে অর্থবহ রাখে—লাল দেখলেই পাঠক জানবেন, "এটি একটি সূচক।"

### খ. মাত্রা-রুল (মাত্রা-rule) — সাইটের স্বাক্ষর
বাংলা লিপির সবচেয়ে স্বতন্ত্র বৈশিষ্ট্য হলো **মাত্রা**—অক্ষরের মাথার ওপর দিয়ে চলে যাওয়া অনুভূমিক রেখা, যা বিচ্ছিন্ন অক্ষরকে একটি শব্দে বেঁধে ফেলে।

আর-রিসালাহর কার্ড ও সেকশনের চারদিকে বর্ডার থাকবে না। থাকবে **কেবল উপরে একটি ১px রেখা**—মাত্রার মতো, যা নিচের বিষয়বস্তুকে ধরে রাখে।

```
─────────────────────────      ← মাত্রা-রুল (১px)
আখলাক ও পরিবার                 ← রুবরিক আইব্রাউ
যবানের হিফাজত: যে অস্ত্র
আমরা রোজ ব্যবহার করি
১২ মিনিট · উমায়র হামদি
```

চারদিকে বর্ডারওয়ালা কার্ডের তুলনায় এটি হালকা, দ্রুত পড়া যায়, এবং মোবাইলে ঘন গ্রিডেও দমবন্ধ লাগে না। এটিই সেই একক উপাদান যা দিয়ে সাইটটিকে মনে রাখা যাবে।

### গ. কাগজ, রঙিন নয়
পটভূমি হবে সামান্য জলপাই-ধূসর আভার কাগজ (`#F7F5EF`)—কমলাঘেঁষা ক্রিম নয়। মূল কালি বিশুদ্ধ কালো নয়, বরং সবুজাভ কালি-কালো (`#171A18`), যেমনটি পুরোনো কালিতে হয়। এটি দীর্ঘ পাঠে চোখের ওপর চাপ কমায় এবং সাধারণ ওয়েবসাইট থেকে সূক্ষ্মভাবে আলাদা করে।

> **যে ফাঁদ সচেতনভাবে এড়ানো হয়েছে:** সবুজ-সোনালি গ্রেডিয়েন্ট, গম্বুজ-মিনারের সিলুয়েট, চাঁদ-তারা, জ্যামিতিক প্যাটার্নের ভারী ব্যাকগ্রাউন্ড, ঝুলন্ত লণ্ঠন। এগুলো ইসলামি পরিচয় বোঝায় না—কেবল সাজসজ্জা করে, এবং প্ল্যাটফর্মটিকে গুরুত্বহীন দেখায়। আমাদের ইসলামি পরিচয় আসবে টাইপোগ্রাফি, কালির রঙ, স্থাপত্যিক অনুপাত ও সংযম থেকে।

### টাইপ স্কেল

মোবাইল-ফার্স্ট। মোবাইলে অনুপাত ১.২, ডেস্কটপে ১.২৫। `clamp()` দিয়ে মসৃণ।

```css
--step--1: clamp(0.83rem, 0.81rem + 0.10vw, 0.89rem);   /* মেটা, ক্যাপশন */
--step-0:  clamp(1.06rem, 1.02rem + 0.20vw, 1.19rem);   /* মূল লেখা */
--step-1:  clamp(1.27rem, 1.20rem + 0.36vw, 1.49rem);   /* উপশিরোনাম */
--step-2:  clamp(1.52rem, 1.40rem + 0.60vw, 1.86rem);   /* H3 */
--step-3:  clamp(1.83rem, 1.64rem + 0.94vw, 2.33rem);   /* H2 */
--step-4:  clamp(2.19rem, 1.91rem + 1.42vw, 2.91rem);   /* H1 */
--step-5:  clamp(2.63rem, 2.20rem + 2.12vw, 3.64rem);   /* হিরো */
```

**মূল লেখার আকার মোবাইলে ~১৭px থেকে শুরু।** বাংলা লিপিতে যুক্তাক্ষর ও মাত্রার কারণে একই পয়েন্ট-সাইজে ল্যাটিনের চেয়ে ঘন দেখায়—তাই স্বাভাবিকের চেয়ে সামান্য বড় ও বেশি লাইন-উচ্চতা প্রয়োজন। এটি ঐচ্ছিক নয়।

### লাইন-উচ্চতা ও পরিমাপ

```css
--leading-tight:  1.24;   /* বড় শিরোনাম */
--leading-snug:   1.42;   /* উপশিরোনাম, কার্ড শিরোনাম */
--leading-body:   1.85;   /* বাংলা মূল লেখা — উদার */
--leading-arabic: 2.05;   /* আরবি — সবচেয়ে উদার */

--measure:        38rem;  /* পাঠের সর্বোচ্চ প্রস্থ (~৬৫ অক্ষর) */
--measure-narrow: 32rem;
--measure-wide:   52rem;
```

বাংলা মূল লেখায় ১.৮৫ লাইন-উচ্চতা ইচ্ছাকৃতভাবে উদার। ঘন সেট করা বাংলা টেক্সট মোবাইলে দ্রুত ক্লান্তিকর হয়।

### অক্ষর-ব্যবধান
বাংলা লিপিতে `letter-spacing` **প্রয়োগ করা হবে না**—এটি যুক্তাক্ষর ভেঙে দেয় এবং রেন্ডারিং নষ্ট করে। কেবল ল্যাটিন বড় হাতের লেবেল ও আইব্রাউয়ে `0.08em`।

### বাংলা সংখ্যা
তারিখ, পড়ার সময়, রেফারেন্স ক্রমিক—সব **বাংলা সংখ্যায়** (১২ মিনিট, ৩ মার্চ ২০২৬)। ব্যতিক্রম: URL, ইংরেজি গ্রন্থের প্রকাশসাল, ISBN। একটি ইউটিলিটি ফাংশন `toBn(n)` সব জায়গায় ব্যবহৃত হবে।

## ৪. স্পেসিং

৪px ভিত্তি, ৮px ছন্দ।

```css
--sp-1: 0.25rem;  --sp-2: 0.5rem;   --sp-3: 0.75rem;  --sp-4: 1rem;
--sp-5: 1.5rem;   --sp-6: 2rem;     --sp-7: 3rem;     --sp-8: 4rem;
--sp-9: 6rem;     --sp-10: 8rem;
```

**সেকশন-ছন্দ:** মোবাইলে সেকশনের উল্লম্ব প্যাডিং `--sp-7` (৩rem), ডেস্কটপে `--sp-9` (৬rem)। এর কমে সেকশনগুলো মিশে যায়, বেশিতে মোবাইলে অতিরিক্ত স্ক্রল।

**প্রবন্ধের ভেতরের ছন্দ:**
```css
p + p        { margin-top: var(--sp-5); }   /* 1.5rem */
h2           { margin-top: var(--sp-8); margin-bottom: var(--sp-4); }
h3           { margin-top: var(--sp-6); margin-bottom: var(--sp-3); }
blockquote   { margin: var(--sp-7) 0; }
```

## ৬. উপাদান (Components)

### কার্ড — মাত্রা-রুল প্যাটার্ন
```
─────────────────────────────   ← ১px --rule; হোভারে --ink, ২০০ms
আখলাক ও পরিবার                  ← --step--1, --font-ui, --rubric, uppercase-ish
যবানের হিফাজত: যে অস্ত্র         ← --step-1, --font-display, --ink
আমরা রোজ ব্যবহার করি
                                 ← --sp-3
কথার আঘাত রক্ত ঝরায় না, তাই    ← --step--1, --ink-soft, ২ লাইন ক্ল্যাম্প
আমরা একে আঘাত বলেই মনে করি না।
                                 ← --sp-4
১২ মিনিট · উমায়র হামদি          ← --step--1, --font-ui, --ink-faint
```

নিয়ম:
- ব্যাকগ্রাউন্ড নেই, বক্স-শ্যাডো নেই, চারদিকে বর্ডার নেই
- হোভারে: উপরের রেখা `--rule` → `--ink`, শিরোনাম সামান্য গাঢ়। কার্ড ওঠে না, নড়ে না
- সম্পূর্ণ কার্ড ক্লিকযোগ্য (`::after` overlay), কিন্তু ফোকাস-রিং শিরোনামের ওপর
- কার্ডের মধ্যে উল্লম্ব ব্যবধান `--sp-6`; কোনো বিভাজক রেখা নেই—মাত্রা-রুলই বিভাজক

**কার্ডের রূপভেদ:** `article` (উপরের মতো) · `feature` (ছবিসহ, বড় টাইপ) · `resource` (ভাষা-ব্যাজ ও ধরনসহ) · `author` (গোল ছবি বা আদ্যক্ষর) · `topic` (গণনাসহ কম্প্যাক্ট) · `announcement` (তারিখ-ব্লক বামে)

### বোতাম

```
প্রাথমিক        ভরাট --deep, লেখা --paper, radius 2px
                হোভার: --deep-2। ফোকাস: 2px --focus রিং, 2px offset

মাধ্যমিক        ১px --rule-strong বর্ডার, স্বচ্ছ
                হোভার: বর্ডার --ink, পটভূমি --paper-raise

টেক্সট          কেবল লেখা, নিচে ১px আন্ডারলাইন ২px offset-এ
                হোভার: আন্ডারলাইন --ink

আইকন            ৪৪×৪৪px ন্যূনতম হিট-এরিয়া, radius 2px
```

**Radius মাত্র ২px, সর্বত্র।** গোলাকার (৮px+) কর্নার সাইটটিকে "অ্যাপ"-এর মতো দেখায়; সম্পূর্ণ কৌণিক (০px) খবরের কাগজের মতো। ২px হলো মুদ্রিত পৃষ্ঠার কাটা প্রান্ত।

**সব ইন্টারঅ্যাক্টিভ উপাদানের ন্যূনতম আকার ৪৪×৪৪px** — মোবাইল-ফার্স্টে এটি আলোচনাসাপেক্ষ নয়।

### আয়াত ও হাদিসের ব্লক

```
┌ (বাম দিকে ২px --rubric রেখা)
│
│   وَقُولُوا لِلنَّاسِ حُسْنًا          ← Amiri, --step-2, RTL, --leading-arabic
│
│   "মানুষের সঙ্গে সুন্দর কথা বলো।"    ← --font-body, --step-0, --ink-body
│
│   — সূরা আল-বাকারা, ২:৮৩             ← --step--1, --ink-soft
└
```
পটভূমি `--paper-deep`, প্যাডিং `--sp-5`। মোবাইলে আরবি টেক্সট `--step-1`-এ নামবে যাতে দুই লাইনে না ভাঙে।

### পুল-কোট
```
        ❝  (রুবরিক রঙে, বড়, opacity .3)

   আখলাকের ঘাটতি আকিদার ভুলের চেয়ে
   বেশি ঘর ভেঙেছে।
   
   ──────                              ← ২৪px রুবরিক রেখা
```
`--font-display`, `--step-2`, পাঠের স্তম্ভ থেকে ডেস্কটপে সামান্য বাইরে বেরোবে।

### মূল বার্তা (Key Takeaways)
প্রবন্ধের শুরুতে, `--paper-deep` পটভূমি, উপরে মাত্রা-রুল। ৩–৫টি বাক্য, প্রতিটির আগে রুবরিক রঙের ছোট বর্গ (৬×৬px) — বুলেট নয়।

### রেফারেন্স তালিকা
ক্রমিক সংখ্যা রুবরিক রঙে, `--font-ui`, ট্যাবুলার। প্রতিটি রেফারেন্সের মধ্যে `--sp-3`, কোনো রেখা নেই।

### গবেষণা-স্তর (`<details>`)
```
┌─────────────────────────────────────────┐
│  ⌄  গবেষণা স্তর: গভীরে যেতে চাইলে       │  ← --font-ui, --step-0
│     আনুমানিক ১৫ মিনিট                    │  ← --step--1, --ink-soft
└─────────────────────────────────────────┘
```
বন্ধ অবস্থায় ১px `--rule-strong` বর্ডার (এটিই একমাত্র চারদিকে-বর্ডারযুক্ত উপাদান—কারণ এটি সত্যিই একটি "বাক্স" যা খোলে)। খোলা অবস্থায় বর্ডার সরে গিয়ে বাম দিকে ২px `--rule-strong` রেখা থাকে। শূন্য JavaScript।

## ৭. ইন্টারঅ্যাকশন ও মোশন

```css
--ease:      cubic-bezier(0.2, 0, 0.2, 1);
--dur-fast:  140ms;
--dur-base:  220ms;
```

অনুমোদিত মোশন—এই তালিকার বাইরে কিছু নয়:
1. রেখা ও লেখার রঙ পরিবর্তন (হোভার/ফোকাস)
2. `<details>` খোলা-বন্ধ
3. মোবাইল মেনু স্লাইড
4. প্রবন্ধের পাঠ-অগ্রগতি রেখা (উপরে ২px, রুবরিক রঙে)

**নিষিদ্ধ:** স্ক্রল-ট্রিগার্ড fade-in, প্যারালাক্স, কার্ড উত্তোলন, সংখ্যা-গণনা অ্যানিমেশন, টাইপরাইটার প্রভাব, ambient কণা।

কারণ দুটি: (ক) ধীর ফোনে এগুলো তোতলায় ও সাইটকে সস্তা দেখায়; (খ) একটি গম্ভীর পাঠ-প্ল্যাটফর্মে চলমান উপাদান পাঠককে বিরক্ত করে।

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

## ৮. অ্যাক্সেসিবিলিটি — ন্যূনতম মান

- সব লেখার কনট্রাস্ট AA বা তার বেশি
- ফোকাস-রিং: `outline: 2px solid var(--focus); outline-offset: 2px` — কখনো `outline: none`
- প্রতিটি পাতায় "মূল অংশে যান" স্কিপ-লিংক
- শিরোনামের ক্রম অলঙ্ঘনীয়: H1 → H2 → H3
- `<html lang="bn">`; আরবি অংশে `lang="ar" dir="rtl"`
- ছবির অর্থবহ `alt`; আলংকারিক ছবিতে `alt=""`
- ফর্মে দৃশ্যমান `<label>`; কেবল প্লেসহোল্ডার নয়
- ত্রুটি বার্তা `aria-live="polite"`
- সব ইন্টারঅ্যাকশন কীবোর্ড দিয়ে সম্পন্ন করা যাবে
- মোবাইল মেনু খোলা অবস্থায় ফোকাস-ট্র্যাপ

## ১০. ভিজ্যুয়াল অ্যাসেট নীতি

**প্রাণীর প্রতিকৃতি নেই।** কভার ছবি হবে চার ধরনের:

1. **জ্যামিতিক বিমূর্ততা** — গিরিহ ও ইসলিমি প্যাটার্নের অংশবিশেষ, ছাঁটা ও বড় করা
2. **কাগজ ও পাণ্ডুলিপির টেক্সচার** — ভাঁজ, প্রান্ত, কালির দাগ, মার্জিনের নোট
3. **স্থাপত্যের বিমূর্ত ফ্রেম** — খিলান, জালি, ছায়ার নকশা, মিহরাবের কুলুঙ্গি
4. **আলো ও ছায়া** — সমতলে পড়া আলো, দিকনির্দেশক আভা

সব ছবি একই ট্রিটমেন্টে: **অবনমিত সম্পৃক্ততা (desaturated), কাগজ-টোনের সঙ্গে মিলিয়ে ওয়ার্ম গ্রেড, উচ্চ কনট্রাস্ট নয়।** একটি সাধারণ CSS ফিল্টার লেয়ার প্রয়োগ করা হবে যাতে বিভিন্ন উৎসের ছবিও একই পরিবারভুক্ত মনে হয়:

```css
.cover img { filter: saturate(0.72) contrast(0.96); }
.cover::after {                       /* কাগজ-টোন ওয়াশ */
  content:''; position:absolute; inset:0;
  background: #F7F5EF; mix-blend-mode: soft-light; opacity:.28;
}
```

আইকন: **Lucide** (স্ট্রোক ১.৫px), শুধু যেখানে অপরিহার্য। আলংকারিক আইকন নয়।

## ১১. লোগো

চূড়ান্ত লোগো নেই। Claude Code Agent যে দিকনির্দেশনায় তৈরি করবে:

**গঠন:** বাংলা শব্দচিহ্ন "আর-রিসালাহ" প্রধান, নিচে ছোট আকারে আরবি «الرسالة»।

**ধারণা:** বাংলা "আ"-এর মাত্রাটিকে বাড়িয়ে পুরো শব্দচিহ্নের ওপর দিয়ে টেনে নেওয়া—যা সাইটের মাত্রা-রুলেরই বড় সংস্করণ। লোগো ও লেআউট একই ভাষা বলবে।

```
  ─────────────────────────
   আ র - রি সা লা হ
        الرسالة
```

**শর্ত:** কেবল টাইপোগ্রাফিক, কোনো চিত্রকল্প নয় (গম্বুজ/চাঁদ/বই/কলম নয়)। এক রঙে কাজ করবে। ২৪px উচ্চতায় পাঠযোগ্য থাকবে। SVG + PNG, হালকা ও গাঢ় দুই সংস্করণে। ফেভিকন: বর্গক্ষেত্রে কেবল "রি" যুক্তাক্ষর, মাত্রাসহ।
