# ইনফরমেশন আর্কিটেকচার ও সাইটম্যাপ

## ১. স্থপতির সিদ্ধান্ত

আপনার তালিকায় ১৯টি সম্ভাব্য পেজ ছিল। আমি সেটিকে পুনর্গঠন করেছি একটি নীতির ভিত্তিতে:

> **একটি বিষয়ের একটিই স্থায়ী ঠিকানা থাকবে। বাকি সব পাতা সেই ঠিকানায় পৌঁছানোর পথ।**

এর ফলে যে পরিবর্তনগুলো এসেছে:

**যা একীভূত করা হলো**
- "Research" আলাদা পোস্ট-টাইপ নয় — প্রবন্ধের ভেতরের একটি স্তর। তবে `/research` নামে একটি সূচিপাতা থাকবে, যেখানে যেসব প্রবন্ধে গবেষণা-স্তর আছে সেগুলো তালিকাবদ্ধ।
- "Search" আলাদা পেজ নয় — হেডারে একটি ওভারলে, যা `/search?q=` URL-ও সমর্থন করে (শেয়ারযোগ্যতার জন্য)।
- "Newsletter/Join" আলাদা পেজ নয় — প্রতিটি পাতায় উপস্থিত। তবে `/subscribe` একটি সরল ল্যান্ডিং পেজ থাকবে, যাতে হোয়াটসঅ্যাপ বা ফেসবুকে সরাসরি লিংক শেয়ার করা যায়।

**যা যোগ করা হলো**
- `/topics/[topic]` — **বিষয়-হাব**। ক্যাটাগরির চেয়ে সূক্ষ্ম, ট্যাগের চেয়ে গভীর। যেমন "যৌতুক" নিয়ে সব প্রবন্ধ, গবেষণা, রিসোর্স ও খতীব-উপকরণ এক পাতায়। এটি হবে সাইটের সবচেয়ে মূল্যবান SEO সম্পদ।
- `/for-khateebs` — খতীব ও দাঈদের জন্য নিবেদিত প্রবেশদ্বার। একটি সুস্পষ্ট শ্রোতাগোষ্ঠীকে সরাসরি সম্বোধন করলে ফিরে আসার হার বহুগুণ বাড়ে।
- `/glossary` — পরিভাষা কোষ। মাকাসিদ, তাযকিয়া, উসুল, হেজিমনি, সেক্যুলারিজম—প্রতিটি পরিভাষার সংক্ষিপ্ত ব্যাখ্যা। প্রবন্ধ থেকে পরিভাষায় ক্লিক করলে এখানে আসবে।
- `/start-here` — নতুন পাঠকের জন্য নির্বাচিত পথ। "প্রথমে এই পাঁচটি পড়ুন।"

**যা বাদ দেওয়া হলো**
- আলাদা "Categories" পাতা — নেভিগেশন ও ফুটারেই সব ক্যাটাগরি দৃশ্যমান; আলাদা পাতা একটি অতিরিক্ত ক্লিক ছাড়া কিছু নয়।

## ৩. URL কাঠামোর নীতি

**সিদ্ধান্ত: URL slug হবে বাংলা প্রতিবর্ণীকরণে (transliteration), ইউনিকোড বাংলায় নয়।**

```
✅  /articles/joutuk-ekti-sanskritik-byadhi
❌  /articles/যৌতুক-একটি-সাংস্কৃতিক-ব্যাধি
❌  /articles/dowry-a-cultural-disease
```

কারণ: ইউনিকোড URL হোয়াটসঅ্যাপে শেয়ার করলে `%E0%A6%AF%E0%A7%8C...` হয়ে দীর্ঘ ও কুৎসিত হয়ে যায়—আর আমাদের বিতরণের প্রধান মাধ্যমই হোয়াটসঅ্যাপ। ইংরেজি অনুবাদ ব্যবহার করলে বাংলা অনুসন্ধানের সঙ্গে মিল থাকে না।

কোনো URL একবার প্রকাশিত হলে কখনো বদলাবে না। বদলানোর প্রয়োজন হলে ৩০১ রিডাইরেক্ট।

## ৪. কনটেন্ট মডেল (Astro Content Collections)

### collection: `articles`
```ts
{
  title: string
  titleShort?: string          // কার্ড ও নেভিগেশনের জন্য
  slug: string
  category: enum(5)
  subcategory: string
  topics: string[]             // বিষয়-হাবের সংযোগ
  excerpt: string              // ১৪০–১৮০ অক্ষর
  authors: string[]            // authors collection-এর reference
  publishedAt: date
  updatedAt?: date
  readingTime: number          // মিনিট, বাংলা সংখ্যায় রেন্ডার হবে
  featured: boolean
  pillar: boolean              // স্তম্ভ-লেখা: বিষয়-হাবে শীর্ষে থাকবে
  cover: { src, alt, prompt }  // prompt = Magnific জেনারেশন প্রম্পট
  keyTakeaways: string[]       // ৩–৫টি
  pullQuote?: string
  references: Reference[]
  academicResources: Resource[]
  researchNote?: string        // স্তর ২ (MDX slot হিসেবেও দেওয়া যায়)
  researchDirections?: string[]
  hasKhutbahResource: boolean  // Phase 2
  hasLeaflet: boolean          // Phase 2
  related?: string[]           // ম্যানুয়াল; খালি থাকলে স্বয়ংক্রিয়
  status: 'draft' | 'review' | 'published'
}
```

## ৫. নেভিগেশন

### প্রধান নেভিগেশন (৫টির বেশি নয়)
```
প্রবন্ধ  ·  বিষয়  ·  গবেষণা  ·  রিসোর্স  ·  আমাদের কথা
                                              [খোঁজ]  [যুক্ত হোন]
```

**"বিষয়"** একটি ড্রপডাউন—পাঁচটি ক্যাটাগরি ও শীর্ষ ছয়টি বিষয়-হাব দেখাবে। বাকি সব লিংক ফুটারে।

**মোবাইলে:** হ্যামবার্গার নয়, নিচে একটি **স্থায়ী তিন-আইটেম বার**: `প্রবন্ধ · খোঁজ · যুক্ত হোন`। উপরে কেবল লোগো ও মেনু। কারণ—আমাদের ৮০%+ পাঠক মোবাইলে, এবং বৃদ্ধাঙ্গুলের নাগালে থাকা নিচের বার উপরের হ্যামবার্গারের চেয়ে বহুগুণ বেশি ব্যবহৃত হয়।

### ব্রেডক্রাম্ব
```
হোম  ›  প্রবন্ধ  ›  আখলাক ও পরিবার  ›  যৌতুক: একটি সাংস্কৃতিক ব্যাধির ব্যবচ্ছেদ
```
কেবল একক প্রবন্ধ, রিসোর্স ও ঘোষণার পাতায়। JSON-LD `BreadcrumbList` সহ।

## ৬. সম্পর্কিত কনটেন্টের যুক্তি

স্বয়ংক্রিয় নির্বাচনের অগ্রাধিকার ক্রম:

1. একই `topics`-এর মধ্যে সবচেয়ে বেশি মিল (৩টি পর্যন্ত)
2. একই `subcategory`
3. একই `category`, ভিন্ন লেখক
4. **ইচ্ছাকৃত সেতু:** আখলাকের লেখার নিচে অন্তত একটি চিন্তা-বিভাগের লেখা, এবং উল্টোটাও

চতুর্থ নিয়মটি সচেতন। যিনি "শাশুড়ি-পুত্রবধূ" পড়তে এসেছেন, তাঁকে "ব্যক্তিস্বাতন্ত্র্যবাদ" পর্যন্ত নিয়ে যাওয়াই আমাদের দাওয়াতি কাজ।

## ৭. খোঁজ (Search)

**Pagefind** ব্যবহার করা হবে—build-এর সময় স্ট্যাটিক ইনডেক্স তৈরি হয়, সার্ভার লাগে না, এবং ইউনিকোড বাংলা ভালোভাবে সামলায়।

শর্ত: বাংলা যুক্তাক্ষর ও `আ/া`-ধরনের বৈচিত্র্য যাচাই করে দেখতে হবে। Pagefind-এর ফলাফল সন্তোষজনক না হলে বিকল্প: প্রতিটি প্রবন্ধের সঙ্গে `searchKeywords[]` ফিল্ড যোগ করে সরল ক্লায়েন্ট-সাইড ফাজি ম্যাচ (Fuse.js, ~৬kb)।

খোঁজ খালি থাকলে শূন্য বাক্স নয়—জনপ্রিয় বিষয় ও সাম্প্রতিক লেখা দেখাবে।

## ৮. পাঠকের পথ (User Journeys)

**সংশয়ী বিশ্ববিদ্যালয় ছাত্র**
হোয়াটসঅ্যাপ লিংক → "সংশয় ভয় পাওয়ার বিষয় নয়" → শেষে সম্পর্কিত: "আধুনিকতা" → বিষয়-হাব: সংশয় → ইমেইল সাবস্ক্রিপশন

**নববিবাহিতা**
গুগল: "শাশুড়ির সাথে সম্পর্ক ইসলাম" → প্রবন্ধ ৩ → করণীয় অংশ → সম্পর্কিত: "অধিকারের ভাষা, ইহসানের ভাষা" → হোয়াটসঅ্যাপ আপডেট

**খতীব**
`/for-khateebs` → বিষয় বাছাই → প্রবন্ধ + গবেষণা-স্তর → খুতবা রিসোর্স ডাউনলোড (ইমেইল দিয়ে) → মাসিক তালিকায় যুক্ত

**গবেষক**
`/resources` → ভাষা: আরবি, বিষয়: আধুনিকতা → গ্রন্থপঞ্জি → সংশ্লিষ্ট প্রবন্ধের গবেষণা-স্তর

**খতীব-পথ ও গবেষক-পথ সবচেয়ে কম ট্রাফিক আনবে, কিন্তু সবচেয়ে মূল্যবান সম্পর্ক তৈরি করবে।** এদের জন্য আলাদা প্রবেশদ্বার রাখার কারণ এটিই।
